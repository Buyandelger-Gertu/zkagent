# ZkAgent — Android гүүр

ZKTeco терминалаас (xFace600) нэвтрэлтийн цохилтыг LAN дотор татаж,
`time-registration` backend рүү HTTPS-ээр илгээх Android апп.

```
xFace600 ◄──LAN, порт 4370──► ZkAgent (Android) ──HTTPS──► backend
```

Бүх холболт **гадагш** чиглэнэ — роутер дээр порт нээх, тогтмол IP авах
шаардлагагүй. Утас байранд үлдэж, та хаанаас ч өгөгдлөө харна.

---

## Хурдан эхлэх

```bash
chmod +x gradlew build-apk.sh

./build-apk.sh test        # протоколын тестүүд (сүлжээ, утас хэрэггүй)
./build-apk.sh             # APK хөрвүүлэх
./build-apk.sh install     # USB-ээр холбогдсон утсанд суулгах
```

Эхний удаад Gradle болон хамаарлуудыг татна — 5–10 минут. Дараа нь
хормын дотор.

APK: `app/build/outputs/apk/debug/app-debug.apk`

### Android Studio-гоор

**Open** → энэ хавтас → Sync → Run. Ижил үр дүн.

## Утсан дээр тохируулах

Апп нээгдэхэд нэг дэлгэц гарна. Дараах дарааллаар хий:

**1. Backend**

| Талбар | Утга |
|---|---|
| Хаяг | `https://hr.gertu.mn` эсвэл `http://192.168.1.180:3000` |
| Гүүрийн токен | `biometric_devices.bridge_token` |

**Backend шалгах** дарж токен зөв эсэхийг батал. Хоосон багц илгээж
хариу авна — өгөгдөл өөрчлөгдөхгүй.

**2. Терминал**

| Талбар | Утга |
|---|---|
| Нэр | Үндсэн орц |
| IP | `192.168.1.104` |
| Порт | `4370` |
| Comm Key | `123456` (тавиагүй бол хоосон) |

**Терминал шалгах** дарж холболт, хэрэглэгчийн тоо, сүүлийн бичлэгүүдийг
хар.

**3. Батерейн хязгаарлалтаас хасах** ← энэ товчийг заавал дар

Үүнийг алгасвал Android хэдхэн цагийн дараа процессыг хязгаарлаж эхэлнэ.
Foreground service ч үүнээс бүрэн хамгаалагдахгүй.

**4. Эхлүүлэх**

Байнгын мэдэгдэл гарч ирнэ: `Үндсэн орц · 61 цохилт илгээв`

## Мөчлөг бүрт юу болох

1. Терминал руу LAN дотор 4370-аар залгаж, Comm Key-ээр баталгаажна
2. Цаг шалгана — 2 минутаас их зөрвөл тааруулна
3. Бүх логийг татна *(ZK протоколд "сүүлээс хойшхийг" гэж хүсэх боломжгүй)*
4. Тэмдэглэлээс хойшхийг шүүнэ
5. `/api/device-bridge/punches` рүү 500-аар багцлан илгээнэ
6. Амжилттай бол тэмдэглэлээ урагшлуулна

**Өгөгдөл алдагдахгүй.** Терминал өөрөө бүх түүхээ хадгалдаг тул агент
хэдэн өдөр унтарсан ч дахин асахад бүгдийг татна. Алдаа гарвал
тэмдэглэл урагшлахгүй — дараагийн мөчлөгт дахин оролдоно.

## Протоколын нарийн цэгүүд

Эдгээрийг олоход цаг зарцуулсан. Кодыг засахаас өмнө уншина уу.

**Comm Key.** Сүүлийн алхамд гурав дахь байт нь `ticks`-ийн **утга
өөрөө** болно — XOR биш, орлуулна:

```
b[0]^ticks   b[1]^ticks   ticks   b[3]^ticks
```

Энэ нэг байтын зөрүүнээс болж auth бүхэлдээ унана.

**Checksum.** `replyId` дээр бодоод, пакетад `replyId + 1`-ийг бичнэ.
Илгээсэн пакетын checksum өөрийнх нь агуулгатай таардаггүй. Логик бус ч
төхөөрөмж яг үүнийг хүлээдэг. Эхлэх `replyId` нь `0xFFFF - 1`.

**Бичлэгийн хэмжээ.** Загвар болгон дээр өөр: xFace600 дээр **49 байт**,
бусад дээр 40. Таамаглахын оронд `CMD_GET_FREE_SIZES`-аар бичлэгийн
тоог асууж `их бие ÷ тоо` гэж тооцно.

```
uid(2) user_id(24) status(1) timestamp(4) punch(1) [нөөц…]
```

- `status` = танилтын арга: **15 царай**, 1 хурууны хээ, 4 карт
- `punch` = 0 ирсэн, 1 явсан, 4 ИЦ эхэлсэн, 5 ИЦ дууссан

**Нэршил эсрэгээрээ.** ZK-ийн `status` → backend-ийн `verify_mode`,
ZK-ийн `punch` → backend-ийн `status`. Хөрвүүлэлтийг `BridgeClient`
хийнэ. Андуурвал бүх лог "нууц үгээр ирсэн" гэж бичигдэнэ.

**Цаг.** ZK-ийн шахсан uint32 — Unix timestamp биш. Сар бүрийг 31 өдөр
гэж тооцно.

**Нэг session.** Терминал нэг SDK холболт л зөвшөөрнө. ZKBio Time.Net
ажиллаж байхад апп холбогдохгүй.

**Foreground service төрөл.** `specialUse` сонгосон шалтгаан: `dataSync`
нь Android 15 дээр 24 цагт 6 хүртэл цаг гэсэн хязгаартай — 24/7 ажиллах
агентад тохирохгүй.

## Асуудал шийдэх

| Шинж | Шалтгаан |
|---|---|
| `Comm Key буруу (код 2005)` | Терминал дээрх `Menu → COMM. → Comm Key`-тэй тулга |
| `холбогдож чадсангүй` | Утас терминалтай нэг WiFi дээр байна уу; Time.Net хаагдсан уу |
| `Токен танигдсангүй (401)` | `biometric_devices.bridge_token` -той тулга |
| `Төхөөрөмж идэвхгүй (403)` | `biometric_devices.is_active = true` болго |
| Шөнө зогсдог | Батерейн хязгаарлалт, autostart зөвшөөрөл |
| Цохилт орж ирсэн ч `employee_id` NULL | `device_employees` руу PIN холбоос оруулаагүй байна — хэвийн, хожим нөхөгдөнө |

Дэлгэрэнгүй лог:

```bash
adb logcat -s ZkAgent
```

  автоматаар бөглөх)
